# 小程序全屏歌词播放器

## 使用方式

- 先选择歌曲，再点击底部播放器的封面、歌名或空白区域，进入 pages/player/index
- 播放暂停、上一首下一首和进度条会拦截点击冒泡，不因操作这些控件误跳全屏
- 全屏页是原生沉浸页面，保留微信右上角胶囊和系统安全区，返回不停止音频，不重新创建播放会话
- 使用当前歌曲封面作为模糊背景，并加暗色遮罩；封面缺失、非 HTTPS 或加载失败时使用本地渐变背景
- 同步歌词按实际播放进度高亮并居中，拖动音频进度后重新定位；用户手动浏览歌词后暂停跟随，停止操作 3 秒或点击“回到当前歌词”恢复
- 没有时间轴时显示静态歌词，不伪造高亮时间；没有歌词、明确的纯音乐或获取失败均有独立提示，不影响音乐播放
- 不支持点击歌词跳转、逐字卡拉 OK、翻译、编辑或手动校时，音量仍用手机系统按键

## 歌词来源与接口

歌词只按播放会话中的实际音源及实际平台歌曲 ID 获取，不按列表原来源，不用同名歌曲跨来源补词

汽水读取官方公开分享页时间轴，网易云读取官方歌词接口，酷我读取官方歌曲详情及歌词接口，均不调用下载或第三方解析流程

新增云调用接口：

```text
GET /api/miniprogram/playbacks/{id}/lyrics
```

返回字段包括 status、source、source_name、source_track_id、lines、plain_text、fetched_at、retry_after、message，不返回音频地址或平台请求头

| status       | 含义                                                   |
| ------------ | ------------------------------------------------------ |
| synced       | 逐行时间轴歌词，lines 包含 time_ms 和 text             |
| plain        | 无有效时间轴的静态歌词，plain_text 为正文              |
| unavailable  | 音源暂无歌词                                           |
| instrumental | 音源明确标记纯音乐或明确返回纯音乐提示，不根据标题猜测 |
| error        | 临时获取失败，按 retry_after 冷却后允许重试            |

歌词按实际音源信息校验，快速切歌后旧响应被忽略；小程序返回前台时按当前播放进度恢复，不把暂停前的歌词位置当作当前位置

打开全屏、返回、获取或重试歌词不触发音频解析，不增加点击或有效播放计数，不消耗音频刷新额度，不切换实际音源

## 缓存、解析和资源限制

- 复用 provider_cache，键为歌词格式版本、实际来源和歌曲 ID，不新增数据库迁移
- 有歌词缓存 24 小时，无歌词或纯音乐缓存 6 小时，异常使用现有 MUSIC_FAILURE_COOLDOWN，单曲并发请求合并
- 复用有界平台线程池，固定官方 HTTPS 地址、拒绝未核验跳转，单次上游响应最多 2MiB，标准化歌词文本最多 64KiB、2000 行，超限明确返回临时失败，不静默截断
- LRC 解析支持多时间戳、毫秒、排序、同时间合并和 offset，正 offset 表示歌词提前，静态歌词不生成假时间轴
- 歌词作为原生 text 渲染，不作为 HTML 或脚本执行，也不按歌词正文里的 URL 发起请求
- 全屏页不轮询歌词，只在进入、实际曲目变化和主动重试时获取，本机最多缓存 8 首；隐藏页面后取消订阅和定时跟随，音乐继续后台播放
- 临时失败和会话过期不会全局隐藏歌曲或停止当前音频，会话过期时提示重新选择歌曲以获取歌词
