# 聚合搜索、自动续播与朋友圈分享

## 统一搜索

0.6.0 原生小程序移除搜索框下方的音乐来源选择，提交关键词、情绪入口、历史搜索及分页都使用统一搜索，不发送指定来源

后端 `GET /api/search?q=关键词&page=1` 默认聚合汽水、QQ、酷狗、网易云和酷我，每个来源每页检索 4 个候选详情，按来源交错组合成最多 20 个候选，不按同名歌曲跨平台合并，列表仍显示真实歌曲来源与实际音源

聚合任务最多同时请求 2 个来源，继续受已有搜索任务数、提供方有界线程池和验证队列限制，单源失败不阻断其他来源，失败来源可以保留自己的旧缓存并标明状态；元数据搜索不解析音频，只有通过现有完整版验证的歌曲才展示

接口新增 `search_sources` 进度信息，来源状态为 `pending`、`ok` 或 `error`，缓存中仍保留候选 ID，重启后未完成的聚合任务可以恢复；完整性未知、试听与当前无完整版的歌曲不因聚合而放宽限制

为兼容旧客户端，后端暂保留显式 `source` 参数，新的原生小程序不再使用，不新增“全部来源”的歌曲身份，恢复与分享仍使用原始平台歌曲 ID

## 自然结束后的续播

歌曲自然结束后，不再因为当前列表或单曲队列结束而停止，改为从首页推荐候选中随机选择下一首，有其他候选时优先避免紧接着重复当前歌曲；手动上一首、下一首仍使用当前列表

- 当前播放期间只预取推荐详情，不预解析临时音频地址，不提前计点击或播放
- 自动切歌时新建直连播放会话，仍实时解析并验证当前完整版，不回退试听、不在一首歌中途换源
- 自动会话使用延迟点击统计，只有收到实际 `onPlay` 才记录点击、有效播放与最近播放，失败尝试不增加有效播放
- 当前音源不适合小程序直连时，暂时跳过该候选，继续选择其他歌曲，不将 Web 可用的歌曲全局隐藏；暂时跳过记录有冷却时间，不是永久黑名单
- 无可播放歌曲时保持“正在获取／验证”的等待状态，后端分批采集，验证通过后自动续播，不因为空结果直接结束
- 网络连接失败或超时明确提示，停止自动请求；用户点击播放可以重新尝试
- 请求限流或本地服务繁忙采用冷却后重试，不使用紧密循环，也不重复消耗播放刷新额度
- 手动暂停、耳机停止、主动切歌或销毁播放器会取消等待，迟到结果不会恢复用户已经暂停的音乐

后端 `GET /api/home?refill=true` 用于需要补充推荐时请求后台采集，`collection_failed` 表示采集网络失败，`retry_after` 给出空结果时的建议等待秒数；返回歌曲不足或暂时为空不代表失败

采集以最多 10 次上游查询为一批，轮换来源、关键词和页码，游标保存在 `catalog:all` 缓存中，避免每次都从汽水和第一页开始；沿用 `MUSIC_FAILURE_COOLDOWN` 限制批次频率，达到待验证上限时先处理已有候选，不无限堆积数据库和内存任务

正常首页没有可播放歌曲时同样会在冷却后续采，即使旧版本曾保存了 6 小时的空推荐缓存，也不会一直等待该缓存到期；已有推荐采集记录后，服务端每 60 秒独立检查并补充不足的推荐池，不依赖小程序一直发轮询请求，确认采集网络失败后暂停这一路自动续采，新的访问可以在冷却后重新尝试

小程序空结果轮询只在连续播放意图仍有效时持续，页面普通列表轮询仍按前台／后台切换暂停，背景播放器的续播意图不随页面隐藏被主动取消；微信系统可能限制后台 JavaScript 和网络执行，锁屏跨曲与断网恢复需以真机结果为准，不能把自动化测试当作“系统永远不会中断”的保证

## 朋友圈分享

全屏播放器新增“朋友圈”入口，好友／群聊分享保留，首页与搜索页也声明朋友圈分享能力

微信原生朋友圈分享通过右上角菜单完成，页面内“朋友圈”按钮负责展示指引，不调用不存在的直接发布 API，也不自动发布内容

1. 点击播放器中的“朋友圈”
2. 点击右上角“···”，选择“分享到朋友圈”
3. 在微信提供的界面中确认发送

分享歌曲只包含稳定来源、平台歌曲 ID 和编码后的歌名、歌手等检索提示，不包含临时音频地址、播放会话、用户身份、收藏状态或数据库编号

朋友圈单页模式仅展示歌曲文字或页面简介，不执行登录、云调用、音频播放或页面重定向；从微信提供的完整小程序入口进入后，再使用既有歌曲恢复流程验证和播放

规则参考 [微信朋友圈分享](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/share-timeline.html)，菜单可用性、个人主体能力和系统差异以实际微信账号与真机结果为准，不承诺通过页面按钮直接打开朋友圈发布窗口

## 更新与验收

本次需要同时更新 FastAPI 和原生小程序，先部署新后端，再将新开发版设为体验版，旧后端默认仍可能只搜索汽水，不能只更新小程序就认为已启用聚合

本次没有新增数据库迁移，沿用 `0006`，如果此前尚未执行北京时间结构升级，应先按照 [数据库时间规则](database-time.md) 完成升级，再部署本版本

README、运行环境变量和默认关键词来源不变，不提交审核或发布正式版

自动化测试覆盖五源分页、并发上限、缓存与旧缓存降级、空推荐续采、网络错误、限流冷却、手动暂停取消、快速切歌、实际播放统计、朋友圈单页和分享参数安全

体验版仍需复测：搜索后自然结束进入首页推荐、空库恢复、连续锁屏跨曲、耳机停止、网络失败后的手动重试，以及两个微信账号间的好友与朋友圈打开效果
