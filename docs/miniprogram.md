# 原生微信音乐小程序

## 当前版本与访问入口

当前为 0.2.0 原生界面开发版，使用 TypeScript、WXML、WXSS，不使用 web-view，现有 Web 保持独立

| 入口                 | 路径                    | 作用                                   |
| -------------------- | ----------------------- | -------------------------------------- |
| 默认首页             | pages/home/index        | 发现音乐、情绪入口、推荐卡片与歌曲列表 |
| 搜索页               | pages/search/index      | 关键词、来源切换、分页及结果验证进度   |
| 诊断页               | pages/diagnostics/index | 关于听见中的检查连接与播放事件         |
| 旧体验二维码兼容入口 | page/index/index        | 自动进入默认首页                       |
| 第一阶段旧入口       | pages/verify/index      | 自动进入默认首页                       |

**设置体验版时优先填写 pages/home/index，不带开头的斜杠，不填 .html、.wxml 或云托管地址**

此前二维码自动填入 page/index/index，与第一阶段声明的 pages/verify/index 不一致，扫码会提示页面不存在；新版本声明了兼容页，并通过 entryPagePath、页面首项和开发者工具启动配置统一首页，未知页面另有回首页兜底

选择新开发版本为体验版后重新生成或使用对应二维码，只有部署后端不会更新小程序体验包，旧体验版本也不会因为 GitHub 推送自动替换

## 页面和播放器

- 发现页保留 Web 的浅色风格、品牌区、主题区、情绪关键词入口、推荐卡片、歌曲来源及实际数量，最多从已通过曲库展示 100 首
- 搜索页支持汽水音乐、网易云音乐和酷我音乐，使用已提交关键词分页，不将输入框尚未提交的内容混入当前分页
- 封面使用原生 image，缺失、非 HTTPS 或加载失败时显示本地代码生成的占位效果，不通过云公网代理图片
- 底部播放器显示封面、歌名、歌手、实际音源、实际音频进度，支持播放暂停、上一首下一首及进度拖动，不显示试听或完整性类型标签
- 全应用仅初始化一个 BackgroundAudioManager，页面切换只切换订阅，不停止音频，音量使用手机系统按键
- 前台验证期间每 3 秒更新，空闲每 60 秒更新，页面隐藏停止轮询，返回前台补刷新，快速切换关键词或来源忽略旧结果
- 暂不可用歌曲从列表、卡片和播放队列移除，重新验证通过后可恢复，后台验证不增加点击或播放统计
- 第一阶段的验证横幅不再作为首页内容，检查连接和播放事件入口位于“关于听见”中
- 没有登录、收藏、歌单或历史页面，作者为 DataShare，仅供个人非商业使用

## 云调用与后端

AppID 为 `wxe1af0ed55ed257b7`，云环境为 `prod-d1ghaho8i283f4b26`，服务名为 `music`

推荐、搜索、会话创建、刷新与统计使用 wx.cloud.callContainer，不需要云托管公网地址；实际音频直接连接音乐平台的 HTTPS 临时地址，不保存整首音频

后端至少部署包含 Alembic 0003 和原生播放接口的版本，端口 80、单 worker，控制台最大实例数为 1，SQLite 和内存限流尚不支持多实例

| 小程序接口                                   | 用途                                         |
| -------------------------------------------- | -------------------------------------------- |
| POST /api/miniprogram/songs/{id}/playbacks   | 实时获取已验证完整版并做无专用请求头直连预检 |
| GET /api/miniprogram/playbacks/{id}          | 查询会话、实际音源、链接版本和临时 audio_url |
| POST /api/miniprogram/playbacks/{id}/started | 实际 onPlay 后按会话幂等计播放               |
| POST /api/miniprogram/playbacks/{id}/refresh | 当前实际音源最多刷新一次，不中途换源         |

列表复用 /api/home、/api/search、/api/sources，Web 代理播放通道不变，直连不兼容不影响 Web 歌曲展示，实际没有可靠完整版时沿用暂时隐藏与复检

音源及其重定向必须为通过安全检查的公网 HTTPS，不能附带 Cookie 或服务端专用请求头交给客户端，不以试听替代，不通过额外公网代理绕过平台限制

默认推荐关键词以 .env.example 为唯一来源，页面情绪按钮只是用户主动搜索入口，不替代后台推荐关键词配置

## 本地开发和上传

在项目根目录执行：

```powershell
cd miniprogram
npm ci
npm test
```

微信开发者工具导入 miniprogram 目录，读取 project.config.json，原生构建目录为 dist，默认启动 pages/home/index，不关闭域名合法性校验

本机上传使用微信官方 miniprogram-ci，私钥必须在仓库外，不能使用 AppSecret，也不能把私钥或构建产物提交到 Git

```powershell
cd miniprogram
$env:WECHAT_UPLOAD_KEY_PATH = '仓库外上传私钥的绝对路径'
npm run upload
```

- 上传前执行构建和全部原生测试，检查 AppID、Git 已提交状态、默认入口与所有注册页面产物、上传私钥及敏感文件
- 构建禁止 WXML 表达式中使用 HTML 实体形式的运算符，例如 &lt;= 或 &amp;&amp;，表达式使用原始运算符，品牌文字使用原始 & 而非显示实体文本
- 版本号为 package.json 版本加短 Git 提交号，上传备注包含对应提交，成功后本地结果在被 Git 忽略的 miniprogram/.local/last-upload.json
- 默认 CI 机器人为 1，可通过 WECHAT_UPLOAD_ROBOT 选择 1～30，上传只更新开发版本，不提审、不发布正式版，也不会代替管理员选为体验版
- 实际上传返回成功才报告成功，上传失败不无限重试，微信原始异常只提取必要脱敏诊断
- 官方本机上传工具依赖仍有已知安全告警，只处理可信源码，不进入后端容器或小程序运行包，未宣称依赖告警已修复
- 上传后建议恢复 IP 白名单，只允许实际上传出口，不能把云托管出口当成本机上传出口
