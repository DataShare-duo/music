# 播放页布局与手势

## 页面设计

0.6.1 全屏播放器采用封面主视觉，封面下方展示当前与下一句歌词，背景继续使用当前歌曲封面的模糊图层

- 收藏、喜欢、分享使用大图标和轻量文字，不添加虚构的收藏数或分享数
- 收藏选中显示暖金色，喜欢选中显示柔粉色，二者状态独立
- 分享保留微信原生好友／群聊入口，删除页面内无法直接调起发布界面的朋友圈按钮，也不再主动开启朋友圈菜单
- 旧朋友圈卡片的安全参数解析与单页落地兼容保留，不影响已经发出的链接
- 底部依次为“歌词／封面切换、播放／暂停、当前队列”，不新增播放模式或额外个人数据功能
- 点击队列可展开当前播放列表，当前歌曲高亮，可以点选其他歌曲；点选当前歌曲不会重新解析音源或增加统计

## 上下划切歌

封面、两行歌词预览和歌曲信息区域支持手势，操作提示直接显示在歌曲信息下方

| 操作           | 效果                             |
| -------------- | -------------------------------- |
| 上划           | 当前播放队列的下一首             |
| 下划           | 当前播放队列的上一首             |
| 点击底部“歌词” | 展开完整歌词，保持滚动与自动跟随 |
| 点击底部“封面” | 回到大封面与两行歌词预览         |
| 歌曲自然播完   | 保持原规则，自动接续首页推荐     |

只识别单指、900 毫秒以内、纵向位移至少 56 逻辑像素的明确手势，纵向距离还需达到横向距离的 1.5 倍，轻点、长按、横划、多指和取消手势不切歌

完整歌词的滚动区域、进度条、底部按钮和队列列表不绑定切歌手势，展开歌词时可以在下方歌曲信息区域切歌，避免上下滚动歌词时误切歌

切歌解析期间忽略新的切歌手势，页面隐藏、会话切换、打开队列或切换封面／歌词视图会取消尚未完成的手势，旧事件不会覆盖当前歌曲

原生背景播放器和耳机上一首／下一首能力保持不变，返回页面或切到微信聊天不停止音乐

## 检查与体验版验收

自动化覆盖手势方向、短距离／横向／多指／取消、加载与页面隐藏、旧会话事件、队列同步与失效歌曲移除、歌词切换以及既有播放行为

布局预览只用于检查窄屏、常规手机与大屏的排版，不等于微信真机验收，体验版请重点检查

1. 上划、下划各切一首，拖动进度、滚动歌词和滚动队列不误触
2. 收藏、喜欢选中颜色正确，好友／群聊分享正常，页面不再出现朋友圈按钮
3. 队列选中当前歌曲不重播，失效歌曲从队列移除
4. 自然播完继续首页推荐，锁屏和耳机控制保持可用
5. iOS 与 Android 的底部安全区、中文长歌名、无封面和无歌词状态
