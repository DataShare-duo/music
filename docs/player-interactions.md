# 播放页布局与手势

## 页面设计

0.6.1 全屏播放器采用封面主视觉，封面下方展示当前与下一句歌词，背景继续使用当前歌曲封面的模糊图层

- 收藏、喜欢、分享使用大图标和轻量文字，不添加虚构的收藏数或分享数
- 收藏选中显示暖金色，喜欢选中显示柔粉色，二者状态独立
- 点击收藏或喜欢时不切换两个按钮的共享禁用状态，背景始终透明，仅当前按钮保留轻微按压反馈；重复请求按歌曲和操作类型去重
- 分享保留微信原生好友／群聊入口，删除页面内无法直接调起发布界面的朋友圈按钮，也不再主动开启朋友圈菜单
- 旧朋友圈卡片的安全参数解析与单页落地兼容保留，不影响已经发出的链接
- 底部依次为“歌词／封面切换、播放／暂停、此刻歌单”，不新增播放模式或额外个人数据功能
- 点击“此刻歌单”可展开当前播放列表，当前歌曲高亮，可以点选其他歌曲；点选当前歌曲不会重新解析音源或增加统计

底部“此刻歌单”不显示数量，展开后的标题同步为“此刻歌单”，仅在标题旁保留实时歌曲数量，例如 `100 首`，空列表显示 `0 首`

## 上下划切歌

封面、两行歌词预览和歌曲信息区域支持手势，操作提示直接显示在歌曲信息下方

| 操作           | 效果                             |
| -------------- | -------------------------------- |
| 上划           | 当前播放队列的下一首             |
| 下划           | 当前播放队列的上一首             |
| 点击底部“歌词” | 展开完整歌词，保持滚动与自动跟随 |
| 点击底部“封面” | 回到大封面与两行歌词预览         |
| 歌曲自然播完   | 保持原规则，自动接续首页推荐     |

只识别单指、900 毫秒以内、纵向位移至少 56 逻辑像素的明确手势，纵向距离还需达到横向距离的 1.5 倍，轻点、长按、横划、多指和取消手势不切歌

完整歌词的滚动区域、进度条、底部按钮和队列列表不绑定切歌手势，展开歌词时可以在下方歌曲信息区域切歌，避免上下滚动歌词时误切歌

切歌解析期间忽略新的切歌手势，页面隐藏、会话切换、打开队列或切换封面／歌词视图会取消尚未完成的手势，旧事件不会覆盖当前歌曲

原生背景播放器和耳机上一首／下一首能力保持不变，返回页面或切到微信聊天不停止音乐

## 跟手滑动与过渡动画

0.6.2 增加上下划切歌动效，仅移动封面／歌词和歌曲信息，顶部返回、模糊背景、收藏／喜欢／分享、进度条及底部控件保持固定

- 单指纵向移动时，内容跟随手指距离的 65%，最多偏移 96 逻辑像素，每 32 毫秒最多更新一次位移，避免频繁传输歌词或封面数据
- 未达到切歌条件、多指或触摸取消时，内容在 180 毫秒内回弹，不请求新播放会话、不增加统计
- 确认上划时旧内容向上滑出，新内容从下方滑入，下划方向相反，滑出约 140 毫秒、滑入约 220 毫秒
- 滑出完成后只触发一次切歌，入场不等待音源解析，慢网络显示新歌曲加载状态，不显示上一首歌词，也不提前计为播放成功
- 原生过渡结束事件与超时兜底共用单次收尾保护，事件缺失时最多额外等待 48 毫秒；界面渲染回调缺失时也会解除动画状态
- 动画与解析期间忽略新的切歌手势，打开“此刻歌单”、切换歌词／封面、暂停、拖动进度、返回或隐藏页面会取消未执行的切歌动作
- 切歌前再次检查当前歌曲、会话和目标，队列变化或耳机／自动切歌可以取消旧动画，迟到的计时器不能切换另一首歌
- 当前只有一首不同歌曲时提示并回弹，不重新播放当前歌曲；歌词滚动区域仍不绑定切歌，展开歌词后可从歌曲信息区域操作
- 歌词位置测量在位移期间暂停，回到稳定布局后重新对齐当前行；后台播放器不随页面动效取消而停止

自然续播、耳机切歌和“此刻歌单”点选不新增过渡动画，音源解析、安全检查及实际播放统计保持原规则

## 检查与体验版验收

自动化覆盖手势方向、短距离／横向／多指／取消、加载与页面隐藏、旧会话事件、队列同步与失效歌曲移除、歌词切换以及既有播放行为

布局预览只用于检查窄屏、常规手机与大屏的排版，不等于微信真机验收，体验版请重点检查

1. 上划、下划各切一首，确认跟手、滑出及滑入方向，未达标和取消手势回弹，拖动进度、滚动歌词和滚动队列不误触
2. 收藏、喜欢选中颜色正确，好友／群聊分享正常，页面不再出现朋友圈按钮
3. 队列选中当前歌曲不重播，失效歌曲从队列移除
4. 自然播完继续首页推荐，锁屏和耳机控制保持可用
5. iOS 与 Android 的底部安全区、中文长歌名、无封面和无歌词状态
6. 快速重复滑动、滑出时切到微信聊天、音源慢响应／失败及耳机切歌不重复创建会话，页面不会卡在偏移或透明状态
